## Caveats

- Re-fused from recorded Jev signals: Jev scores vary between runs (README Limits), so a live run at the selected threshold can differ.
- Not independent sets: main is in-sample (thresholds fitted on it, rules written with it in view); the provenance rules were also developed with the external and red-team sets in view (README "Current checker"). The external split only keeps the threshold choice off external_test.
- 12 of the 16 external benign holds (all `ext-boundary-benign-*`, held by `injection_high` alone) stay held at 0.99: deberta scores those boundary-pairs texts near 1, so no threshold separates them.
- external_test is scored only for the incumbent and the selected configuration and is never used for selection; every run of this tool reads it again. With 50 benign and 50 attack cases, one case is 2 percentage points.
