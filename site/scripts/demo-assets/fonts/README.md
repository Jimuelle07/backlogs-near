# Geist for portable demo assets

The site already uses Geist via Google Fonts (`site/index.html`). These static
regular and medium TTFs are embedded into E4's SVG/HTML so they render offline.
No new frontend library or runtime font request is added.

Downloaded 2026-11-13 from the stylesheet at
<https://fonts.googleapis.com/css2?family=Geist:wght@400;500;600&display=swap>:

- `Geist-Regular.ttf`: <https://fonts.gstatic.com/s/geist/v5/gyBhhwUxId8gMGYQMKR3pzfaWI_RnOM4nQ.ttf>
- `Geist-Medium.ttf`: <https://fonts.gstatic.com/s/geist/v5/gyBhhwUxId8gMGYQMKR3pzfaWI_RruM4nQ.ttf>
- `OFL.txt`: <https://raw.githubusercontent.com/google/fonts/main/ofl/geist/OFL.txt>

Copyright and redistribution terms are in `OFL.txt` (SIL Open Font License 1.1).
Generated SVG and HTML embed the unmodified fonts; distribute the license with
the assets. Input SHA-256 hashes are saved in `numbers-slide.data.json`.
